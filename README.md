# 🖱️ ESP32 MPU6050 Wireless BLE Air Mouse

[![ESP32](https://img.shields.io/badge/ESP32-BLE_HID-blue.svg)](https://www.espressif.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Hardware](https://img.shields.io/badge/Hardware-DIY-green.svg)](#)

An open-source, gesture-controlled **3D Bluetooth HID Air Mouse** built using an **ESP32** microcontroller and an **MPU6050** 6-axis Gyroscope & Accelerometer sensor[cite: 1]. 

Move your mouse cursor seamlessly across Windows, macOS, Linux, and Android devices simply by moving your hand in the air[cite: 1].
